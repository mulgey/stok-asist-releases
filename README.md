# Stok Asist — Windows dağıtımları

Bu depo Windows x64 kurulum dosyalarını ve uygulamanın doğruladığı imzalı güncelleme bilgilerini barındırır. Kaynak kod bu depoda bulunmaz.

Sürüm kurulumları `vMAJOR.MINOR.PATCH` yayınlarında yer alır. Uygulamanın beta kanalı `update-beta` yayınındaki `windows-x64-production.json` dosyasını kullanır.

Uygulama güncelleme bilgisinin imzasını ve indirilen kurulum dosyasının bütünlüğünü doğrular. Kurulum dosyasını indirmek kurum lisansı sağlamaz.

Lisans yönetimi, anahtar kurtarma ve başvuru bilgi tamamlama arayüzü GitHub Pages üzerinden sunulur. Bu arayüzde özel anahtar veya sunucu erişim anahtarı bulunmaz; yetkili işlemler lisans hizmeti tarafından doğrulanır.
